This is an interseting game that allow you to check your response time by tracing and clicking the designated target.Moreover, there is an enemy as well which leads to reduction in your points by -1 on each tap so you have to avoid it and focus on your main target which gives positive points eventually, increasing your concentration. User have to beat and set their highest score under a given time period of 30 seconds.
I developed this in a workshop, through the help of javascript and p5.js, by using the javascript I applied the game's main funtionality,like mouse clicking detection,time detector and score tracker.
